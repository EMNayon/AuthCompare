# AuthCompare — Authentication vs Authorization Explainer

একটি ইন্টারঅ্যাক্টিভ ও ভিজ্যুয়াল ওয়েব অ্যাপ্লিকেশন যা বাস্তবসম্মত হোটেল অ্যাক্সেস অ্যানালজির মাধ্যমে **Authentication (AuthN)** এবং **Authorization (AuthZ)**-এর মধ্যকার পার্থক্য সহজ ভাষায় ব্যাখ্যা করে।

## 🚀 কী কী আছে এই প্রজেক্টে?

- **সহজ ভাষায় ব্যাখ্যা (Theoretical Cards):** AuthN এবং AuthZ-এর মৌলিক বিষয়াবলি, কাজের অর্ডার এবং ব্যর্থতার ক্ষেত্রে যথাক্রমে `401 Unauthorized` ও `403 Forbidden` স্ট্যাটাস কোড সম্পর্কিত স্পষ্ট বিবরণ।
- **পাশাপাশি তুলনা (Comparison Table):** বিষয়ভিত্তিক পার্থক্যগুলোর একটি কুইক সাইড-বাই-সাইড রেফারেন্স টেবিল।
- **হোটেল অ্যাক্সেস সিমুলেটর (Hotel Access Simulation):** বাস্তব জীবনের ৪টি ভিন্ন চরিত্র (VIP Guest, Standard Guest, Hotel Staff, Intruder/Stranger) নিয়ে একটি লাইভ ও স্বয়ংক্রিয় সিমুলেশন।
  - **Gate 1 (Authentication):** পরিচয় নিশ্চিত করার ধাপ ("তুমি কে?")।
  - **Gate 2 (Authorization):** রোল ও কীকার্ড পারমিশন অনুযায়ী এক্সেস যাচাইয়ের ধাপ ("তুমি কী করতে পারবে?")।
- **লাইভ লগ কনসোল (Live Log Console):** ব্যাকএন্ড বা সিস্টেম লেভেলে কী ঘটছে তা রিয়েল-টাইমে লগ আকারে দেখার সুবিধা।
- **প্রিমিয়াম ডার্ক থিম UI:** চোখের আরামদায়ক মডার্ন গ্রেডিয়েন্ট ডার্ক থিম, বাটন ইন্টারঅ্যাকশন এবং মসৃণ অ্যানিমেশন।

কোনো সার্ভার বা প্যাকেজ ইন্সটলেশনের ঝামেলা ছাড়াই প্রজেক্টটি সরাসরি ব্রাউজারে রান করতে পারবেন:

1. রিপোজিটরিটি ক্লোন বা ডাউনলোড করুন।
